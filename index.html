🚀 PUBLICAR EN GITHUB PAGES (GRATIS)

  1. Crea una cuenta o inicia sesión en github.com y haz clic en New repository (ej. hospitality-timer).
  2. Guarda este archivo exactamente con el nombre index.html y súbelo al repositorio (Add file → Upload files).
  3. Ve a la pestaña Settings del repositorio → sección Pages en el menú lateral.
  4. En Build and deployment → Branch, selecciona main y carpeta / (root), luego pulsa Save.
  5. En 1 minuto tendrás tu enlace público listo para proyectar desde cualquier navegador en el evento.
